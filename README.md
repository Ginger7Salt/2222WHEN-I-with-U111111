# 熔巧机 · WHEN I with U

> 一个非商业化的私人陪伴空间。  
> 让电子伴侣、日常记录与现实生活，在同一个房间里慢慢连接起来。

WHEN I with U 的正式中文名是 **熔巧机**。

这是一个面向个人使用的 AI 陪伴空间。你可以在这里与自己的电子伴侣进行长期交流，留下消息、日记、影像、旅行记录和生活片段，也可以通过 MCP 将天气、出行、音乐、饮食和健康等现实服务带入对话。

项目目前仍在持续开发中，新的子应用、交互和视觉页面会逐渐加入。使用过程中如果遇到问题，欢迎提交 Issue 或加入交流群反馈。

---

## 项目特点

- 私人化的 AI 电子伴侣空间
- 支持 OpenAI-compatible API
- 角色长期聊天与消息记录
- 本地保存角色、聊天和生活数据
- 日记、旅行、影像和碎片记录
- 今日留物与角色主动陪伴
- 角色动态与生活片段
- 虚拟群聊空间
- 多角色群聊
- 本地数据导出与恢复
- 支持 MCP 外部服务连接
- 适合安装到手机主屏幕使用

## 当前空间

### Hub

整个空间的入口。

可以从这里查看角色、置顶影像、快速记录，并进入其他子空间。

### Messages

与角色进行一对一的长期交流。

这是目前 MCP 主要使用的场景。其他空间通常不会读取消息框中的完整聊天记录，而是根据角色基础资料和相关生活记录运行。

### Diaries

保存独自书写或与角色共同留下的日记片段。

角色也可以主动向你发送日记，你也可以将自己写下的内容发送给角色，让角色回信。

### Travel

与角色一起进行旅行，并保存旅途中留下的记录。

### Snapshots

保存像拍立得一样的瞬间、影像和相关评论。

角色之间也可以在这里产生互动。

### Pebbling

留下轻小、随意的生活片段。

你可以把它当作一个不需要认真组织语言的私人角落。

### Imaginarium

虚拟群聊空间。

可以填写群聊信息，并让多个角色一起参与交流。

### The Ensemble

从角色库中选择多个角色，将他们带入同一个群聊。

你也可以在这里为自己设置不同身份。

### Living Habitat

观察角色共同守护的生态空间与生命记录。

### Ephemera

将日常事件保存成票根、收据、卡片或其他可以收藏的物件。

### Memory

查看你和角色在不同消息框中留下的记忆，并进行编辑和删除。

## MCP 支持

目前项目支持通过 MCP 将外部服务连接到角色对话中，并渲染相应的小卡片。

当前可以兼容：

- 麦当劳
- 滴滴打车
- Apple Watch
- 天气
- Apple 健康
- 网易云音乐
- 瑞幸咖啡

MCP 可以让角色获得更加贴近日常生活的互动方式，例如：

- 查看天气
- 获取出行或打车相关信息
- 连接健康数据
- 查看运动与设备状态
- 播放或推荐音乐
- 获取餐饮相关信息
- 连接咖啡和日常消费服务

目前 MCP 主要在 **Messages 的一对一沟通** 中使用。

具体可用服务取决于 MCP 服务端配置、授权状态以及外部服务本身是否正常运行。

## 开始使用

### 1. 配置 AI 服务

首次使用前，请先进入设置页面，配置自己的 AI 服务。

需要填写：

- Base URL
- API Key
- 模型名称

项目使用兼容 OpenAI 接口格式的 AI 服务。填写完成后，可以通过连接测试确认配置是否可用。

> API Key 只保存在当前设备的本地浏览器存储中。请不要在公共设备上保存自己的密钥。

### 2. 添加角色

创建一个角色并填写基础资料。

角色资料会影响后续的聊天、主动陪伴、日记、动态和其他空间内容。

### 3. 开始聊天

回到 Hub 或 Messages，与角色进行第一次交流。

随着聊天和生活记录的积累，角色会逐渐获得更多与你相关的上下文。

### 4. 配置 MCP

如果需要使用 MCP，请进入设置页面完成 MCP 相关配置和授权。

MCP 当前主要用于 Messages 的一对一聊天场景。

### 5. 安装到手机主屏幕

如果希望更方便地使用，可以通过浏览器的“分享”功能，将网站添加到手机主屏幕。

建议：

1. 先将网站安装到主屏幕
2. 再完成 API 和角色配置
3. 定期导出重要数据备份

## 数据与隐私
WHEN I with U 使用浏览器本地数据库保存角色、消息、影像和其他生活记录。

这些内容不会因为打开另一个页面而自动上传到公共账户。

只有在使用你配置的 AI 服务时，相关请求内容才会发送到对应的 API 服务。不同 AI 服务商对数据的保存和使用规则可能不同，请在使用前确认对应服务商的隐私政策。

请注意：
清除浏览器站点数据可能导致本地记录丢失
卸载应用前请先导出数据
更换设备时需要手动迁移备份
API Key 请妥善保管
不建议在公共设备上使用个人 API Key
MCP 服务可能需要额外的授权和隐私权限
重要内容建议定期导出备份。
